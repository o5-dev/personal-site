**Personal site** is my portfolio: a small page about me, the things I build (SnapMath, Face Lock, nRF Box) and the best ways to reach me.

## Features

- Hero, About me, Projects and Contact sections
- Project cards with tech tags and links to GitHub
- Contact buttons for GitHub, Slack, Instagram, Discord, Email and Stardance
- Custom Chelsea Market font and a grayscale design made in Figma
- Responsive, works on phone and PC

## Run it yourself

It is a single static page with no build step or server. Fork the repo, then enable **Settings → Pages** (deploy from the root of your branch). To try it locally, run `py -m http.server 8000` and open http://localhost:8000.
