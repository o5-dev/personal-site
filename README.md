**Personal site** is my maker portfolio, designed like a piece of electronics: an LCD that types out who I am, push buttons, resistors, rainbow jumper wires and a breadboard. It covers me, what I build (SnapMath, Face Lock, nRF Box) and how to reach me.

## Features

- LCD hero with a typing animation that cycles through different messages
- Animated push buttons ("View projects" and "Contact me") that pulse and press in on hover and click
- Project cards with tech tags, GitHub links and a hover animation
- Contact buttons for GitHub, Slack, Instagram, Discord, Email and Stardance
- Designed in Figma, using the Jersey 10 pixel font (the LCD uses Press Start 2P)
- Responsive: the cards stack on phones and the decorative wires hide on narrow screens
- Respects "reduce motion": the animations are switched off for people who ask for that
